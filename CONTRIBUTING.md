# Contributing

**This repository is generated. Please do not send pull requests.**

Every file under `reports/`, along with `index.html`, `sitemap.xml` and `NOTICE`, is produced
by a publishing tool in a separate repository. A merged pull request would be overwritten
without warning the next time a report is published, so a change made here does not survive.

## What to do instead

**Something in a report looks wrong.** Please open an issue. Say which report, which card,
and what you believe the correct identification is. A disagreement about a specific detection
is the most useful thing anyone can send: these pages exist to be checked, and a corrected
false positive improves the model that produced it.

**A credit or licence is wrong.** Open an issue, or contact me directly if you would rather
not do it in public. If you operate one of the feeds used here and want attribution changed
or content removed, say so and it will be actioned promptly rather than debated.

**Something is broken.** Broken media, a page that does not load, an accessibility problem:
open an issue with the report name and your browser.

**A security or privacy concern.** See SECURITY.md rather than opening a public issue.

## What is not accepted

Changes to report content, model outputs, or historical detections. The record of what a
model said on a given day stays as it was, including where it was wrong. Corrections are
recorded alongside the original rather than replacing it, because a page that quietly edits
its past errors cannot be used to judge the pipeline.
